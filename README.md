# Coffee Analysis - An Thượng (Đà Nẵng)

Hệ thống cào dữ liệu Google Maps, OCR thực đơn (Menu OCR) và phân tích tiện ích/cơ sở vật chất các quán cafe tại khu phố Tây An Thượng (Ngũ Hành Sơn, Đà Nẵng) đẩy lên Supabase, kèm giao diện web tra cứu.

## Cấu trúc dự án

```
coffee_analysis/
├── pipeline/       # Pipeline cào dữ liệu Google Maps, OCR thực đơn & trích xuất tiện ích
│   └── colab_reference/  # Mã nguồn trích xuất tham khảo từ notebook gốc
├── web/            # Ứng dụng web Next.js khởi tạo từ kungfu-stack

└── README.md
```
